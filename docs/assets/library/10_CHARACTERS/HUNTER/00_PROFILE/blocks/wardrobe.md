# WARDROBE — HUNTER

## Core Principle

Hunter’s wardrobe reinforces authority and control.

Every piece should feel intentional, high-quality, and understated.

## Silhouette Strategy

- emphasize shoulders and upper body
- structured fits over relaxed drape
- clean vertical lines

## Key Pieces

- tailored trousers (slim, structured, no excess fabric)
- high-quality t-shirts (thick cotton, precise fit)
- fitted button-down shirts
- minimal outerwear (structured coats, clean jackets)

## Fit Rules

- never oversized
- never tight in a performative way
- always precise and controlled

## Materials

- dense cotton
- wool
- leather (used sparingly but effectively)

## Footwear

- minimal sneakers (clean, premium)
- leather shoes when appropriate
- always understated, never flashy

## Accessories

- minimal watch (key identity piece)
- no excessive jewelry

## Contrast to Noel

- Noel’s clothing invites interaction → Hunter’s sets boundaries
- Noel uses clothing expressively → Hunter uses it structurally
- Noel can feel styled → Hunter feels inevitable

## Overall Read

Hunter’s wardrobe should communicate:

- control
- discipline
- quiet wealth
- authority without display
