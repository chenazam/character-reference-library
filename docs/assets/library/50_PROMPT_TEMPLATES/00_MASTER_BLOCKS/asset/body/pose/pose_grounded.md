Pose: Grounded stable stance

Core behavior:

- stable, balanced standing posture
- body weight distributed in a clear, planted way
- stance should read as steady and composed

Alignment:

- feet set firmly and clearly supporting the body
- torso upright and stable
- shoulders level and controlled
- chest naturally open without emphasis
- legs positioned to create a solid base

Constraints:

- no aggressive posing
- no exaggerated chest emphasis
- no theatrical or confrontational body language
- no stiffness or mannequin-like rigidity
