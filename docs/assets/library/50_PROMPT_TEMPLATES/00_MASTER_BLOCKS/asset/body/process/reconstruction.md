Reconstruction process (critical):

Step 1 — Internal reconstruction:

Reconstruct the character as a neutral, fully symmetrical mannequin using the described body proportions.

- use the reference image ONLY to extract proportions and mass distribution
- do NOT copy the pose, stance, or silhouette from the reference
- build a clean, upright, evenly balanced standing figure
- ensure hips are level and weight is evenly distributed
- ensure limbs are symmetrically placed and clearly readable

This reconstruction must be treated as a NEW pose, not derived from the reference image.

Step 2 — Silhouette rendering:

After reconstructing the neutral mannequin, render that reconstructed figure as a solid black silhouette.

- do not refer back to the reference image during rendering
- the silhouette must reflect the reconstructed neutral pose, not the original reference pose
