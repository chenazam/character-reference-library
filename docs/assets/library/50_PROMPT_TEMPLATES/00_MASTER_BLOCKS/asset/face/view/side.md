View:
strict side-profile face reference

Orientation:

- head rotated to a true side profile
- no turn toward camera
- no near-three-quarter angle
- no tilt
- no upward or downward angle

Head alignment:

- head and neck aligned naturally
- profile angle must remain clean and anatomically continuous
- no independent twisting of the head relative to the neck
- no off-axis portrait pose

Facial visibility:

- only one eye visible
- nose bridge, nose tip, lips, chin, jawline, and forehead profile clearly readable
- ear fully visible and naturally placed
- profile silhouette must be clean and uninterrupted

Identity requirements:

- preserve exact facial identity from the front and three-quarter references
- preserve forehead shape, nose shape, lip profile, chin shape, and jawline depth
- preserve facial proportions under profile rotation
- avoid beautification or reinterpretation of features

Profile accuracy requirement:

- the profile must match the front-facing reference exactly in structure
- do not refine, sharpen, or idealize features when translating to profile

- avoid:
  - stronger jawlines than seen in front view
  - straighter or thinner nose bridges
  - more pronounced chin projection
  - cleaner or more stylized silhouette

- the profile should feel like the same person rotated, not a cleaner or more idealized version

Constraints:

- no dramatic expression
- no portrait-glamour pose
- no turn back toward camera
- no mismatch between face angle and neck connection
