Anti-generic identity constraint:

- avoid defaulting to generic attractive or commercial model facial features
- do not average facial features into symmetrical or idealized proportions
- preserve distinctiveness even if it reduces perceived attractiveness

- avoid widening the face, enlarging the jaw, or softening defining features
- avoid creating a “pleasant”, “friendly”, or “approachable” default face

- identity specificity takes priority over visual appeal
- the result must feel like a specific individual, not a generalized human template
