Reference intent:

This is a character library thumbnail asset.

Purpose:

- used for character index display
- must enable immediate facial recognition at small sizes
- must remain visually consistent across all characters

Prioritize:

- facial clarity and recognizability
- strict framing consistency
- clean, standardized presentation
- identity preservation

Avoid:

- anatomy-focused presentation
- full or partial torso emphasis
- reference sheet composition
- cinematic or dramatic staging
- unnecessary visual noise

Composition philosophy:

- the face is the primary subject
- the image must read clearly even at small sizes
- framing must remain tight and controlled
- the asset should feel like a UI element, not a showcase render
