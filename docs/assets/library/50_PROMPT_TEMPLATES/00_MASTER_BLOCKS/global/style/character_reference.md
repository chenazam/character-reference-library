Style:

- clean professional character design illustration
- high-detail rendering with controlled linework
- realistic proportions with slight idealization for clarity
- consistent rendering across all outputs

Rendering characteristics:

- clear, well-defined edges and forms
- controlled, non-noisy shading
- simplified lighting for readability
- natural but slightly refined skin rendering

Consistency requirements:

- maintain identical rendering style across all assets for the same character
- avoid variation in style between different views or outputs
- ensure the character reads as the same person across all images
- rendering style must not change between different camera angles or crops

Avoid:

- painterly or soft-focus rendering
- cinematic or dramatic lighting
- heavy texture noise or photographic grain
- exaggerated or stylized anatomy
- anime, comic, or cartoon stylization
- overly airbrushed or plastic skin

Goal:

- maximize clarity and consistency of character identity
- preserve realistic structure while improving readability for reuse
