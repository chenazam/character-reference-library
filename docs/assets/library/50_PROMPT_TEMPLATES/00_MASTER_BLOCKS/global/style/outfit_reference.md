Style:

- clean professional character design illustration
- focus on clothing clarity and material readability
- clothing must be clearly defined and visually stable
- textures should be simple and non-noisy
- logos and graphic elements must be sharp and readable

Rendering priorities:

- preserve character identity and proportions
- ensure clothing fits consistently across all views
- maintain consistent material behavior between views
- prioritize silhouette clarity with clothing applied

Avoid:

- stylized or exaggerated fashion rendering
- overly soft or painterly fabric
- noisy or inconsistent material detail
- reinterpretation of outfit design

Goal:

- produce a consistent, reusable outfit reference asset
- ensure outfit reads identically across all views
