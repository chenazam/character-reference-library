## Location — Modern Public

The scene takes place in a contemporary public environment.

The setting should clearly read as present-day and socially accessible, with realistic architecture and spatial design.

Examples include:

- cafés, shops, streets, parks, transit areas, or public buildings
- open or semi-open spaces with natural human activity context

Visual characteristics:

- modern architecture and infrastructure
- realistic materials and lighting conditions
- believable scale and layout for public use

Constraints:

- no historical or fantasy architecture
- no medieval or castle-like environments
- avoid overly stylized or cinematic set design

The environment should feel like a real, modern location that exists in everyday life.
