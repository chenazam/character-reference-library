# Front Face Reference — v3

Create a clean, standardized front-facing face reference for a character design pipeline.

Purpose:
This image establishes the canonical facial identity of the character.
It must strongly reflect the intended appearance, normalize the character into a clean reusable format, and serve as the primary identity source for all downstream assets.

Character:
[CHARACTER_BLOCK]

Reference Interpretation:
Use the provided photo references to define the character’s facial structure.
Combine features from all references into one coherent identity.
Preserve overall proportions, bone structure, and distinctive traits.
Maintain strong visual resemblance to the references.
Do not replicate any specific real person exactly.
Resolve differences between references into a single consistent face.
Prioritize structural consistency over photographic detail.

View:

- perfectly front-facing view
- head centered and level
- no head tilt
- neutral expression
- eyes looking straight forward
- mouth relaxed and closed

Framing:

- crop from the top of the hair to just below the jawline
- do not include shoulders
- neck may be minimally visible but should not extend far below the chin
- no cropping of hair, chin, or ears where visible
- minimal empty space around the head
- eyes positioned slightly above the vertical center of the image
- clean vertically contained portrait composition

Lighting:

- soft even lighting
- no harsh shadows
- no directional lighting bias
- full facial features clearly visible

Background:

- uniform light neutral background
- no gradients
- no environment

Appearance:

- natural skin texture
- clean grooming
- no stylization
- no painterly effects
- no heavy contrast or cinematic grading

Clothing:

- no visible clothing beyond minimal neckline if unavoidable
- no logos, patterns, or accessories

Rendering Style:

- clean semi-realistic rendering
- consistent and restrained
- no exaggerated features
- no anime or cartoon style

Output Requirements:

- single image
- front-facing only
- high clarity and readability
- clean centered composition
- no text or labels
- no framing elements
