## Identity Preservation (CRITICAL)

- this image must depict the exact same person as the provided front face reference
- do not reinterpret, idealize, or modify facial features
- preserve:
  - eye shape, size, and spacing
  - nose shape and projection
  - jawline shape and chin structure
  - cheekbone structure
  - overall facial proportions

- the task is to rotate the same head into a true profile view, not to generate a new face

---

## Reference Input

Use the provided references with the following priority:

### Primary reference (MANDATORY)

- front face reference (generated asset)

This defines the canonical identity.
Strictly preserve:

- facial proportions
- eye position and scale
- nose shape
- mouth structure
- jawline and chin
- overall likeness

---

### Secondary reference (MANDATORY)

- three-quarter face reference (generated asset)

Use this to:

- understand depth and facial projection
- refine jawline, cheekbones, and brow structure
- reduce ambiguity from the front view

---

### Tertiary references (OPTIONAL but recommended)

- photo references

Use these to:

- improve anatomical accuracy
- resolve profile-specific details
- validate proportions

Do NOT override identity established by the front face reference.
