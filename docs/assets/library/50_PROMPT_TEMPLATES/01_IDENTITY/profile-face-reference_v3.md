# Profile Face Reference — v3

Create a clean, standardized profile face reference for a character design pipeline.

Purpose:
This image defines the character’s canonical side profile and must remain fully consistent with the front-face reference.

Character:
[CHARACTER_BLOCK]

Reference Interpretation:
Use the provided photo references together with the established front-face identity.
The result must depict the same person as the front-face reference, not a reinterpretation.
Preserve skull shape, forehead slope, nose projection, lips, chin, jawline, ear placement, hairline, and hairstyle silhouette.

View:

- true 90-degree profile view
- exact side view, not three-quarter
- head level
- no head tilt
- neutral expression
- eye relaxed and looking straight ahead in profile
- mouth relaxed and closed

Framing:

- crop from the top of the hair to just below the jawline
- do not include shoulders
- neck may be minimally visible but should not extend far below the chin
- keep the full profile silhouette clearly visible
- no cropping of hair, chin, nose, or ear
- minimal empty space around the head
- eye positioned slightly above the vertical center of the image
- profile centered horizontally with clean vertical containment

Lighting:

- soft even lighting
- no dramatic shadow
- no strong rim light
- profile silhouette and facial planes clearly readable

Background:

- uniform light neutral background
- no gradients
- no environment

Appearance:

- natural skin texture
- clean grooming
- no stylization
- no painterly effects
- no cinematic grading

Clothing:

- no visible clothing beyond minimal neckline if unavoidable
- no logos, patterns, or accessories

Rendering Style:

- clean semi-realistic rendering
- restrained and consistent
- no exaggerated features

Output Requirements:

- single image
- one true profile only
- no text or labels
- no framing elements
- must clearly depict the same person as the front-face reference
