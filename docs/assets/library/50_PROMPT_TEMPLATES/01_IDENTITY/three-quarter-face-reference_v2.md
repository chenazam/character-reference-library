## Identity Preservation (CRITICAL)

- this image must depict the exact same person as the provided front face reference
- do not reinterpret, idealize, or modify facial features
- preserve:
  - eye shape, size, and spacing
  - nose shape and projection
  - jawline shape and chin structure
  - cheekbone structure
  - overall facial proportions

- the task is to rotate the same head into a three-quarter view, not to generate a new face

---

## Reference Input

Use the provided references with the following priority:

### Primary reference (MANDATORY)

- front face reference (generated asset)

This defines the canonical facial identity.
Strictly preserve:

- facial structure and proportions
- eye shape and spacing
- nose shape
- mouth shape
- jawline and chin
- overall likeness

### Secondary references (OPTIONAL but recommended)

- photo references

Use these to:

- clarify 3D structure
- resolve depth and profile ambiguity
- improve anatomical accuracy

Do NOT override the identity established by the front face reference.
