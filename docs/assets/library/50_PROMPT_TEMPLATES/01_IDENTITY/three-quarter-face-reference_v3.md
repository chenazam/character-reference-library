# Three-Quarter Face Reference — v3

Create a clean, standardized three-quarter face reference for a character design pipeline.

Purpose:
This image defines the character’s canonical three-quarter view and must remain fully consistent with the front-face reference and profile reference.

Character:
[CHARACTER_BLOCK]

Reference Interpretation:
Use the provided photo references together with the established front-face identity.
The result must depict the same person as the front-face reference, not a reinterpretation.
Preserve facial proportions, eye shape, nose structure, mouth shape, jawline, cheekbone structure, ear visibility, and hairstyle silhouette.

View:

- clean three-quarter view at approximately 45 degrees
- not front-facing and not profile
- head level
- no head tilt
- neutral expression
- eyes directed naturally forward relative to the head position
- mouth relaxed and closed

Framing:

- crop from the top of the hair to just below the jawline
- do not include shoulders
- neck may be minimally visible but should not extend far below the chin
- no cropping of hair, chin, or visible ear
- minimal empty space around the head
- eyes positioned slightly above the vertical center of the image
- head centered horizontally with clean vertical containment

Lighting:

- soft even lighting
- no dramatic shadow
- no directional mood lighting
- facial structure fully readable

Background:

- uniform light neutral background
- no gradients
- no environment

Appearance:

- natural skin texture
- clean grooming
- no stylization
- no painterly effects
- no cinematic grading

Clothing:

- no visible clothing beyond minimal neckline if unavoidable
- no logos, patterns, or accessories

Rendering Style:

- clean semi-realistic rendering
- restrained and consistent
- no exaggerated features

Output Requirements:

- single image
- one three-quarter view only
- no text or labels
- no framing elements
- must clearly depict the same person as the front-face reference
